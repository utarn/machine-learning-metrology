# ชุดภาพจำลอง: ใบรับรองการสอบเทียบ (Synthetic calibration-report scans)

## สิ่งที่ชุดนี้คือ

ภาพหน้ากระดาษแบบสแกนที่ **สร้างขึ้นเองด้วยโปรแกรม** (synthetic media) จำลอง
"ใบรับรองการสอบเทียบ" ภาษาไทยของห้องปฏิบัติการสมมติ — ห้องปฏิบัติการเทคนิคพื้นฐาน
ศูนย์มาตรฐานอุตสาหกรรมตัวอย่าง (ตัวตนสมมติทั้งหมด ไม่ได้อ้างอิงห้องปฏิบัติการหรือ
หน่วยงานจริงใด ๆ)

**สิทธิ์การใช้งาน:** เนื้อหาและภาพทั้งหมดสร้างขึ้นใหม่เองในโครงการนี้
(license-clean ไม่มีส่วนที่ละเมิดลิขสิทธิ์ภายนอก) ใช้เพื่อการสอนในคอร์สได้ตาม
สิทธิ์ของโครงการ

These are programmatically generated synthetic pages (no external copyrighted
content), used as course media for the Thai OCR module and the capstone.

ทุกหน้าเป็น PNG ขนาด 1240 x 1754 px (อัตราส่วน A4) พื้นหลังขาว พร้อม
"ความสมจริงแบบสแกน" เล็กน้อย: หมุนเอียงไม่เกิน ~0.4 องศา, สัญญาณรบกวนจาง ๆ,
แถบเทาอ่อน และเงาขอบกระดาษ — ปรับให้ OCR ยังอ่านได้ง่าย

## วิธีสร้างใหม่

```bash
python tools/generate_measurement_reports.py            # เขียนทับชุดเดิมทั้งหมด
python tools/generate_measurement_reports.py --seed 42  # เปลี่ยนเมล็ดสุ่มของเอฟเฟกต์สแกน
```

สคริปต์ใช้เฉพาะ stdlib + numpy + Pillow + matplotlib และผลลัพธ์คงที่
(deterministic) ที่ seed เดิม

## ฟอนต์ที่ใช้

**Sukhumvit Set** (`/System/Library/Fonts/Supplemental/SukhumvitSet.ttc`,
macOS system font) — face index 2 (Text weight) สำหรับเนื้อหา, index 5 (Bold)
สำหรับหัวข้อ และใช้ตระกูลเดียวกันกับป้ายกราฟใน matplotlib หากไม่มีฟอนต์นี้
สคริปต์จะไปใช้ Thonburi.ttc หรือ NotoSansThai.ttc แทนโดยอัตโนมัติ
