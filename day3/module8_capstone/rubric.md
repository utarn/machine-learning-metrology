# เกณฑ์ให้คะแนน Capstone (M8) — โน้ตบุ๊ก + นำเสนอ 10 นาที

> ใช้กับทุก track (A / B / C) · ทีม 2–3 คน · เต็ม **100 คะแนน เส้นผ่าน 60**
> นี่คือ **การวัดผลของหลักสูตร** (ไม่มี quiz แยก) — ผู้สอนใช้ให้คะแนน
> และให้แต่ละทีมใช้ตรวจตัวเองก่อนขึ้นนำเสนอ

## ผลงานที่ส่ง

1. **โน้ตบุ๊กของ track ที่เลือก** (เริ่มจาก starter ในโฟลเดอร์นี้) — Restart &
   Run All ผ่านหมดก่อนนำเสนอ
2. **นำเสนอ 10 นาที** ต่อหน้าห้อง — ทุกคนในทีมมีส่วนพูด

## ตารางคะแนน

| หมวด | น้ำหนัก | สิ่งที่ประเมิน |
|---|---|---|
| 1. โจทย์และข้อมูล | **10** | นิยามโจทย์ชัด (input → output คืออะไร) · อธิบายที่มาของข้อมูล + citation/license ครบ |
| 2. วงจร ML ครบ + วัดผลซื่อสัตย์ | **25** | data → เทรน → วัดผล รันจบจริง · **split ที่อธิบายได้และไม่มี leakage** (แยกล็อตถ่าย / เซสชันบันทึก / หน้าเอกสาร — ไม่สุ่มปน) · มี baseline ให้เทียบ |
| 3. ผลลัพธ์และการวิเคราะห์ | **20** | metric ถูกกับโจทย์ (accuracy/AUC/CER-style) · อ่าน confusion matrix / anomaly map / ตารางที่สกัดได้ แล้ววิเคราะห์ error เป็นระบบ (กระบวนการ 4 ขั้นของ M7) · ข้อจำกัดของโมเดลระบุตรงไปตรงมา |
| 4. การนำเสนอ 10 นาที | **25** | โครงเวลาครบ (ด้านล่าง) · ทุกคนในทีมพูด · ตอบคำถามเป็น · ควบคุมเวลาได้ |
| 5. Reproducibility & craft | **20** | Restart & Run All ผ่าน · กราฟมีชื่อแกน/legend/หัวข้อ · โค้ดอ่านได้ (ไม่มีเซลล์ตาย) · citation ครบในหัวโน้ตบุ๊ก |

### โครงเวลา 10 นาที (หมวด 4 — ใช้เป็น check-list ของสไลด์)

| นาที | ส่วน | ต้องมี |
|---|---|---|
| 0–2 | โจทย์ + ข้อมูล | ปัญหาของทีมคืออะไร ข้อมูลมาจากไหน มีกี่ตัวอย่าง (แสดงตัวอย่างข้อมูลจริง 1–2 รายการ) |
| 2–5 | วิธี | เลือกวิธีอะไร **และเลือกเพราะอะไร** (ตามเงื่อนไขข้อมูล — เช่น ไม่มี label ชำรุด → PatchCore) |
| 5–8 | ผลลัพธ์ | metric ตัวเลข + กราฟ/ตาราง 1–2 ภาพที่อ่านออกใน 10 วินาที + วิเคราะห์ error ที่เจอ |
| 8–10 | ข้อจำกัด + ต่อยอด | โมเดลพลาดอะไร (ยกตัวอย่างจริง) · ถ้ามีเวลาอีก 1 สัปดาห์จะทำอะไรก่อน |

### เกณฑ์ระดับต่อหมวด

| ระดับ | ความหมาย |
|---|---|
| เต็ม | ครบทุกข้อในหมวด + มีอะไรที่ "เกินชั้นเรียน" เล็กน้อย (เช่น ซ่อมข้อผิดพลาด OCR ด้วยกฎโดเมน, ทดลอง 2 วิธีเทียบกัน, feature ที่ออกแบบเอง) |
| ~80% | ครบทุกข้อในหมวด |
| ~50% | ครบแต่ผิวเผิน — มีของให้เห็นแต่อธิบาย "ทำไม" ไม่ได้ |
| 0 | หมวดนั้นขาด |

## กติกา (gate)

- **Restart & Run All ไม่ผ่าน** → หมวด 5 = 0 คะแนน และคะแนนรวมจำกัดที่ **60/100**
- **นำเสนอเกิน 12 นาที** → หมวด 4 ได้ครึ่งเดียว (ฝึกบรรยายให้จบ 10 นาทีจริง)
- **ใช้ข้อมูลจริงของทีม** ไม่ให้คะแนนพิเศษด้วยตัวมันเอง — แต่ประเมินที่
  "การจัดการข้อมูลจริงอย่างซื่อสัตย์" ในหมวด 2 (split ข้ามล็อต/เซสชัน) และ
  "ความชัดของโจทย์" ในหมวด 1 — ทีมที่ใช้ starter dataset ก็ได้เต็มได้เหมือนกัน
